# C Programming – Functions, Recursion & Basic Programs

This repository contains beginner-level **C programming practice programs** covering functions, recursion, mathematical calculations, Fibonacci series, increment operators, and pattern printing.

##  Programs Included

### 1. Average of Three Numbers

Calculates the average of three floating-point numbers using a user-defined function.

**Concepts:** Functions, `float`, function arguments, return values.

**Formula:**

```text
Average = (a + b + c) / 3
```

---

### 2. Celsius to Fahrenheit

Converts a temperature from Celsius to Fahrenheit using a function.

**Concepts:** Functions, function prototype, floating-point arithmetic.

**Formula:**

```text
F = (C × 9/5) + 32
```

---

### 3. Force Calculation

Calculates force using the formula:

```text
F = m × g
```

where `g = 9.8 m/s²`.

**Concepts:** Functions, mathematical calculations, function arguments.

---

### 4. Fibonacci Series Using Recursion

Finds the Fibonacci value at a given position using a recursive function.

**Concepts:** Recursion, base condition, functions.

The Fibonacci sequence starts as:

```text
0, 1, 1, 2, 3, 5, 8, 13, 21...
```

---

### 5. Increment Operators

Demonstrates the use of:

* Pre-increment: `++a`
* Post-increment: `a++`

**Concepts:** Increment operators and expression evaluation.

> **Note:** The expression `printf("%d %d %d", a, ++a, a++);` involves modifying and reading `a` multiple times without sequencing. In standard C, its behavior is **undefined**, so it should not be used to demonstrate a guaranteed left-to-right or right-to-left result.

---

### 6. Sum of Natural Numbers Using Recursion

Calculates the sum of the first `n` natural numbers using recursion.

For example:

```text
1 + 2 + 3 + ... + 10 = 55
```

**Concepts:** Recursion, functions, base condition.

---

### 7. Star Pattern

Prints a pyramid-like pattern using nested `for` loops.

For `n = 5`:

```text
*
***
*****
*******
*********
```

**Concepts:** Nested loops, `for` loops, pattern printing.

##  How to Run

Make sure you have a C compiler such as **GCC** installed.

Compile:

```bash
gcc filename.c -o program
```

Run:

```bash
./program
```

On Windows:

```bash
program.exe
```
